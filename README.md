# Jogo-GALAGA-Space-Kamikaze-
Kamikaze é um jogo de nave espacial 2D inspirado nos clássicos arcades. O jogador controla uma nave de combate e deve enfrentar ondas de inimigos que surgem continuamente pelo espaço. A cada fase, a dificuldade aumenta, exigindo reflexos rápidos e estratégias para sobreviver.

# game solo

# 4 fases

# objetivos

    1. Alcançar altas pontuações.
    2. Coletar power-ups.
    3. Derrotar chefes.
    4. Completar todas as fases.


# jogador

    - 4 naves e cada nave com sua pria habilidade

    1. normal , zero habilidade
    2. tiro metralhadora
    3. movimentar mais rapido + vida extra
    4. mais dano

# inimigos

    - 4 inimigos com sua habilidade propria

    1. tenta atigir o jogador (KMZ)
    2. nave com escudo
    3. se move atirando
    4. inimigo mais forte

# chefe

    1. vida 100 + tiro arco com espaço no meio


# vida

a cada x ponto (inimigos destruidos) aumenta 1 vida limitando a 3 vidas
